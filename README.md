# VAEZI INDUSTRY
مخزن سایت استاتیک فارسی با تمرکز تحریریه‌ای هدفمند ۹۰٪ ایران و ۱۰٪ جهان.

- صفحات مستقل: خانه، اخبار، جزئیات خبر، پلتفرم‌ها، مقصدها، صفحهٔ اختصاصی مقصد، راهنمای سفر، گزارش، درباره و سیاست انتشار.
- تصاویر محلی SVG به‌عنوان fallback و عکس‌های آرشیوی lazy-load با کیفیت فشرده.
- فید RSS عمومی در `feed.xml`.
- به‌روزرسانی خبرها هر ۶ ساعت از مسیر `scripts/update_rss.py` و GitHub Actions.
- اجرای دستی در Actions → Update tourism RSS news → Run workflow.
- خبرهای خودکار خلاصه‌اند؛ لینک ناشر در کارت حفظ می‌شود. RSS جایگزین بررسی انسانی نیست.
- مقصدها: `destination.html?city=isfahan` یا rasht, yazd, shiraz, kish, desert, tehran, qeshm, persepolis.
